CapView for Windows (베타)
=========================

캡처보드(닌텐도 스위치 2, PS5 등)의 화면과 소리만 띄우는 아주 가벼운 뷰어입니다.

실행 방법
---------
1. CapView.exe를 실행합니다. (설치 버전은 시작 메뉴/바탕 화면의 CapView)
2. 처음 한 번만 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다.
   개인 프로젝트라 코드 서명 인증서가 없어서 그렇습니다.
   → "추가 정보"를 누르고 → "실행"을 누르세요.
3. 화면이 안 나오면: 설정 › 개인 정보 및 보안 › 카메라 에서
   "데스크톱 앱이 카메라에 액세스하도록 허용"을 켜 주세요. (소리는 같은 곳의 마이크)
4. Windows N/KN 에디션이라면 '미디어 기능 팩'이 필요합니다.
   (설정 › 앱 › 선택적 기능 › 기능 추가 › 미디어 기능 팩)

사용법
------
- 오른쪽 클릭: 장치·해상도·오디오·화면 조정 메뉴
- 더블클릭 또는 F: 전체 화면 (Esc로 나가기)
- M: 음소거, ↑/↓: 볼륨
- Ctrl+C: 지금 화면을 클립보드에 복사
- Ctrl+E: 화면 조정 (밝기·대비·채도·감마·색조)
- Ctrl+T: 항상 위에 표시, Ctrl+0: 실제 픽셀 크기, Ctrl+R: 다시 연결

문제가 있으면
-------------
오른쪽 클릭 › "로그 폴더 열기"에서 capview.log 파일을 보내 주세요.
